# ДАСТАН — Қазақ тілі мен мәдениетінің цифрлық платформасы

**ДАСТАН** — қазақ тілін заманауи тәсілмен үйренуге, қолдануға және дамытуға, сондай-ақ қазақ мәдениетін танытуға арналған толыққанды веб-платформа. Бұл «Қазақ тілін қолдануға арналған IT өнімдер» облыстық (Қызылорда) байқауына қатысатын IT өнімі.

## 🎯 Мақсаты
Қазақ тілін үйренетіндерге (бастаушыдан орта деңгейге дейін) ойын әлеміне (геймификация) және дауыс технологиясына негізделген, сондай-ақ қазақ мәдениетін (жыр, мақал-мәтел, тарих, ою-өрнек, тағам, киім) танытатын цифрлық құрал беру.

## ✨ Мүмкіндіктері (16 модуль)

### Тіл (7 модуль)
1. **Басты бет** — үздік күн, деңгей, «бүгінің сөзі», жалпы статистика, мәдениет бөлімдеріне кілттер.
2. **Сөздік** — 8 санат, 61 сөз, 3D айналатын карточкалар, транскрипция, мысал сөйлемдер, дауыспен тыңдау.
3. **Грамматика** — сөз таптары, септік (жіктеу), жалғаулар, етістік бойынша 4 сабақ.
4. **Оқу** — интерактивті мәтін: сөзге бассаңыз/ұссаңыз мағынасы шығады, түсіну сұрақтары.
5. **Тыңдау** — дауыспен айтылған сөзді табу (Web Speech / Text-to-Speech).
6. **Сөйлеу** — сөзді микрофонға айтып, жүйе тануы және кері байланыс беру (Speech Recognition).
7. **Тест** — сұрақтар, дұрыс/қате кері байланыс, есеп, ең жақсы нәтиже.

### Мәдениет (7 модуль)
8. **Мақал-мәтелдер** — 45 мақал-мәтел, 6 бағыт (Еңбек, Білім, Достық, Өмір, Әдеп, Жастық), айналатын карточкалар, дауыспен тыңдау.
9. **Жыр-дастан** — 4 дастан (Қобыланды батыр, Ер Төстік, Көзі қаралы қыз, Жібек) + Абай жырлары. Мәтін, дауыспен тыңдау, түсіну сұрақтары.
10. **Жаңылтпаштар** — 15 жаңылтпаш, 3 деңгей (жеңіл/орташа/қиын), дауыспен тыңдау, айту жаттығуы.
11. **Дәстүрлі тағамдар** — 12 тағам (бешбармақ, қазы, қымыз, құрт...), сипаттамалары, дауыспен тыңдау.
12. **Дәстүрлі киім-кешек** — 10 бұйым (шапан, желің, түмен, әбже...), сипаттамалары, дауыспен тыңдау.
13. **Аңыз-әңгімелер** — 5 аңыз (домбыра, тұлпар, қымыз, шанырак, қарлығаш), мәтін, дауыспен тыңдау, түсіну сұрақтары.
14. **Қазақ тарихы** — 8 сабақ (ежелгі дәуірден 1991-ге дейін), нақты фактілер, түсіну сұрақтары.
15. **Ою-өрнек** — 8 ұлттық ою (қошқар мүйіз, қос қарағай, тұмар...), SVG суреттері, мағынасы.
16. **Прогресс** — деңгей сақинасы, XP, 14 медаль, меңгерілген сөздер, мақал/жыр/тарих статистикасы.

### Аккаунт
- **Тіркелу/кіру** — email+пароль, парольді көрсету «глаз» батырмасы, **Google-мен бір батырмамен кіру**, прогрессті бұлтта (Firestore) сақтау — кез келген құрылғыда жалғасады.

## 🏅 Геймификация
- **XP жүйесі** — әр әрекет үшін ұпай (сөз, дұрыс жауап, сабақ, оқу, сөйлеу, мақал ашу, жыр оқу, тарих сұрағы).
- **Деңгейлер** — Бастаушы → Кіші оқушы → ... → Тіл шебері.
- **Медальдар** — 14 жетістік: тіл модульдері + мәдениет (Дана сөз, Жыршы, Жаңылтпашшы, Тарихшы, Оюгер...).
- **Үздік күн (streak)** — күн сайын қайта оралуға ынталандырады.

## 🛠️ Технологиялар
- **HTML5 + CSS3 + Vanilla JavaScript** (негізгі логика — бір файл, фреймворк жоқ; контент — 3 бөлек JS файлда).
- **Firebase Auth** — email/пароль және Google Sign-In (тегін Spark жоспары).
- **Cloud Firestore** — пайдаланушы прогресінің бұлттық көші (`users/{uid}`), қауіпсіздік ережелерімен.
- **Web Speech API** — `speechSynthesis` (дауыспен оқу) және `SpeechRecognition` (сөйлеу тану).
- **localStorage + SHA-256 (WebCrypto)** — жергілікті кэш және демо-режимде парольдерді хэш түрінде сақтау.
- **SVG** — эмблема, ою-өрнек суреттері, қазақ ою-өрнегі (векторлық, кескінізсіз).
- **Responsive дизайн** — телефон, планшет, десктопқа бейімделеді.
- Заманауи UX/UI: жылы-жарық минимал стилі, анимациялар, 3D карточкалар, Навигацияда ТІЛ / МӘДЕНИЕТ топтамалары.

## 🎵 Дауыс технологиясы
- **edge-tts (kk-KZ-AigulNeural)** — 72 дайын MP3 файл (сөздер, мақалдар, мәтіндер) — табиғи, акцентсіз қазақша дауыс.
- **Web Speech API** — браузердегі `speechSynthesis` (резерв) және `SpeechRecognition` (сөйлеу тану, Chrome/Edge).

## 🔑 Google-мен кіруді қосу (Firebase орнату — 3 минут)
1. https://console.firebase.google.com — Google аккаунтқа кір → **«Проект қосу»** → есімі «soz».
2. Жоба ашылғанда: **Project settings (⚙️) → General → Your apps → `</>` (Web)** → «Register app».
3. Көрінген `firebaseConfig` объектін (apiKey, authDomain, projectId...) көшіріп, `index.html`-дегі `window.FBCFG = {...}` орынына жап (қою жері комментмен белгіленген), commit + push.
4. **Firestore Database** → «Create database» → тест режимінде бастап, **Rules** табына мынаны жап:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. **Authentication → Sign-in method** → **Google** және **Email/Password** қосқыштарын қос.
6. (Егер Google батырмасы қате берсе) **Authentication → Settings → Authorized domains** тізімінде `shakhann.github.io` барын тексер.

Жоба кілтсіз болса сайт **демо-режимде** жұмыс істей береді: аккаунт тек сол браузерде сақталады, Google батырмасы өшірулі.
