# СӨЗ — Қазақ тілін үйренетін цифрлық платформа

**СӨЗ** — қазақ тілін заманауи тәсілмен үйренуге, қолдануға және дамытуға арналған толыққанды веб-платформа. Бұл «Қазақ тілін қолдануға арналған IT өнімдер» облыстық байқауына қатысатын IT өнімі.

## 🎯 Мақсаты
Қазақ тілін үйренетіндерге (бастаушыдан орта деңгейге дейін) ойын әлеміне (геймификация) және дауыс технологиясына негізделген, керек дегенде қолданатын цифрлық құрал беру.

## ✨ мүмкіндіктері (9 модуль)
1. **Басты бет** — үздік күн, деңгей, «бүгінің сөзі», жалпы статистика.
2. **Сөздік** — 8 санат, 60+ сөз, 3D айналатын карточкалар, транскрипция, мысал сөйлемдер, дауыспен тыңдау.
3. **Грамматика** — сөз таптары, септік (жіктеу), жалғаулар, етістік бойынша 4 сабақ.
4. **Оқу** — интерактивті мәтін: сөзге бассаңыз/ұссаңыз мағынасы шығады, түсіну сұрақтары.
5. **Тыңдау** — дауыспен айтылған сөзді табу (Web Speech / Text-to-Speech).
6. **Сөйлеу** — сөзді микрофонға айтып, жүйе тануы және кері байланыс беру (Speech Recognition).
7. **Тест** — сұрақтар, дұрыс/қате кері байланыс, есеп, ең жақсы нәтиже.
8. **Мақал-мәтелдер** — қазақ халқының даналығы, айналатын карточкалар.
9. **Прогресс** — деңгей сақинасы, XP, медальдар, меңгерілген сөздер.

## 🏅 Геймификация
- **XP жүйесі** — әр әрекет үшін ұпай (сөз, дұрыс жауап, сабақ, оқу, сөйлеу).
- **Деңгейлер** — Бастаушы → Кіші оқушы → ... → Тіл шебері.
- **Медальдар** — 8 жетістік (алғашқы сөз, 10/25 сөз, тест, грамматика, оқу, сөйлеу, 500 XP).
- **Үздік күн (streak)** — күн сайын қайта оралуға ынталандырады.

## 🛠️ Технологиялар
- **HTML5 + CSS3 + Vanilla JavaScript** (бір файл, сыртқы тәуелділік/бақылау жүйесі жоқ).
- **Web Speech API** — `speechSynthesis` (дауыспен оқу) және `SpeechRecognition` (сөйлеу тану).
- **localStorage** — прогрессті жергілікті сақтау.
- **Responsive дизайн** — телефон, планшет, десктопқа бейімделеді.
- Заманауи UX/UI: градиенттер, анимациялар, 3D карточкалар, қазақ туының түсі.

## 🚀 Іске қосу
Веб-жоба, сондықтан еш қосымша орнату қажет емес — тек браузерде ашу керек:
1. `index.html` файлын ашыңыз (немесе дайын URL-ге кіріңіз).
2. Ең жақсы тәжірибе үшін **Chrome / Edge** қолданыңыз (дауыс және сөйлеу тану).

## 🌐 Дайын URL
Жоба GitHub Pages-те тұрақты URL арқылы жұмыс істейді (қолданушы аққанынан көрі ашлады).
