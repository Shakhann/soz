# СӨЗ — Қазақ тілін үйренетін цифрлық платформа

**СӨЗ** — қазақ тілін заманауи тәсілмен үйренуге, қолдануға және дамытуға арналған толыққанды веб-платформа. Бұл «Қазақ тілін қолдануға арналған IT өнімдер» облыстық байқауына қатысатын IT өнімі.

## 🎯 Мақсаты
Қазақ тілін үйренетіндерге (бастаушыдан орта деңгейге дейін) ойын әлеміне (геймификация) және дауыс технологиясына негізделген, керек дегенде қолданатын цифрлық құрал беру.

## ✨ мүмкіндіктері (9 модуль)
1. **Басты бет** — үздік күн, деңгей, «бүгінің сөзі», жалпы статистика.
2. **Сөздік** — 8 санат, 60+ сөз, 3D айналатын карточкалар, транскрипция, мысал сөйлемдер, дауыспен тыңдау.
3. **Грамматика** — сөз таптары, септік (жіктеу), жалғаулар, етістік бойынша 4 сабақ.
4. **Оқу** — интерактивті мәтін: сөзге бассаңыз/ұссаңыз мағынасы шығады, түсіну сұрақтары.
5. **Тыңдау** — дауыспен айтылған сөзді табу (Web Speech / Text-to-Speech).
6. **Сөйлеу** — сөзді микрофонға айтып, жүйе тануы және кері байланыс беру (Speech Recognition).
7. **Тест** — сұрақтар, дұрыс/қате кері байланыс, есеп, ең жақсы нәтиже.
8. **Мақал-мәтелдер** — қазақ халқының даналығы, айналатын карточкалар.
9. **Прогресс** — деңгей сақинасы, XP, медальдар, меңгерілген сөздер.
10. **Аккаунт** — тіркелу/кіру (email+пароль, парольді көрсету «глаз» батырмасы), **Google-мен бір батырмамен кіру**, прогрессті бұлтта (Firestore) сақтау — кез келген құрылғыда жалғасады.

## 🏅 Геймификация
- **XP жүйесі** — әр әрекет үшін ұпай (сөз, дұрыс жауап, сабақ, оқу, сөйлеу).
- **Деңгейлер** — Бастаушы → Кіші оқушы → ... → Тіл шебері.
- **Медальдар** — 8 жетістік (алғашқы сөз, 10/25 сөз, тест, грамматика, оқу, сөйлеу, 500 XP).
- **Үздік күн (streak)** — күн сайын қайта оралуға ынталандырады.

## 🛠️ Технологиялар
- **HTML5 + CSS3 + Vanilla JavaScript** (негізгі логика — бір файл, фреймворк жоқ).
- **Firebase Auth** — email/пароль және Google Sign-In (тегін Spark жоспары).
- **Cloud Firestore** — пайдаланушы прогресінің бұлттық көші (`users/{uid}`), қауіпсіздік ережелерімен.
- **Web Speech API** — `speechSynthesis` (дауыспен оқу) және `SpeechRecognition` (сөйлеу тану).
- **localStorage + SHA-256 (WebCrypto)** — жергілікті кэш және демо-режимде парольдерді хэш түрінде сақтау.
- **Responsive дизайн** — телефон, планшет, десктопқа бейімделеді.
- Заманауи UX/UI: жылы-жарық минимал стилі, анимациялар, 3D карточкалар, қазақ ою-өрнегі.

## 🔑 Google-мен кіруді қосу (Firebase орнату — 3 минут)
1. https://console.firebase.google.com — Google аккаунтқа кір → **«Проект қосу»** → есімі «soz».
2. Жоба ашылғанда: **Project settings (⚙️) → General → Your apps → `</>` (Web)** → «Register app».
3. Көрінген `firebaseConfig` объектін (apiKey, authDomain, projectId...) көшіріп, `index.html`-дегі `window.FBCFG = {...}` орынына жап (қою жері комментпен белгіленген), commit + push.
4. **Firestore Database** → «Create database» → тест режимінде бастап, **Rules** табына мынаны жап:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. **Authentication → Sign-in method** → **Google** және **Email/Password** қосқыштарын қос.
6. (Егер Google батырмасы қате берсе) **Authentication → Settings → Authorized domains** тізімінде `shakhann.github.io` барын тексер.

Жоба кілтсіз болса сайт **демо-режимде** жұмыс істей береді: аккаунт тек сол браузерде сақталады, Google батырмасы өшірулі.

## 🚀 Іске қосу
Веб-жоба, сондықтан еш қосымша орнату қажет емес — тек браузерде ашу керек:
1. `index.html` файлын ашыңыз (немесе дайын URL-ге кіріңіз).
2. Ең жақсы тәжірибе үшін **Chrome / Edge** қолданыңыз (дауыс, сөйлеу тану, Google-кіру).
